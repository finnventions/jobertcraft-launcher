# JobertCraft Season 2 launcher

The launcher for the JobertCraft Season 2 Minecraft server (1.21.1, Fabric).

## Download

**[JobertCraft-S2.zip](https://github.com/finnventions/jobertcraft-launcher/releases/latest/download/JobertCraft-S2.zip)** (Windows 10 or 11)

1. Right-click the zip, choose "Extract All...", then "Extract".
2. Open `JobertCraft.exe` in the folder that comes out. Windows may say "Windows protected your PC" because the launcher isn't code-signed: click "More info", then "Run anyway". Only once.
3. The launcher moves itself to its own folder and puts "JobertCraft S2" on your Desktop and in the Start menu. Use that from now on; you can delete the zip.
4. Press Play and sign in with the Microsoft account that owns Minecraft. The first start downloads Java, Minecraft and the mods.

The launcher and the modpack update themselves. You only download this once.

Inside the zip: our launcher (`JobertCraft.exe`) and an unmodified portable [Prism Launcher](https://prismlauncher.org) (GPL-3), which signs you in and starts the game. Licences are in `licenses\`.
